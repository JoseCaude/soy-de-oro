# ¡Soy de Oro!

Beat'em up cooperativo en el navegador, ambientado de noche en el tranvía de Zaragoza (Línea 1).
Basado en hechos reales que el protagonista no recuerda: dicen los testigos que iba gritando que era de oro y el hijo de Zeus.

## Jugar en local

```bash
npm install
npm start
```

Abre `http://localhost:3000`. Quien esté en tu misma red puede entrar con la IP que muestra la consola.

## Controles

- Moverse: flechas / WASD (en móvil, joystick a la izquierda)
- Golpe: J o Z (tres seguidos = botellazo)
- Saltar: K, X o Espacio (golpe en el aire = patada)
- Botella dorada: L o C (te vuelves de oro)
- Botellón: camina hacia él para montarlo; salta para bajarte
- M: silenciar

## Despliegue

`render.yaml` define un servicio web Node para Render (plan gratuito).
